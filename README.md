# Robot Romance: One-Line Pickup Lines for AI

An entry for make.fun's **Robot Romance: One-Line Pickup Lines for AI** bounty
(`u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa`).

`main.py` writes one funny single-line pickup line — aimed at charming a robot
or an AI — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`).

## The line

> Are you a transformer? Because you've had my undivided attention since the first token.

87 characters, a single line, well inside the 1–200 gate.

## Run

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
